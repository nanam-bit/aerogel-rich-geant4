
## Introduction

Ring Imaging Cherenkov (RICH) Detectors identify electrically charged subatomic particles by detecting the cone of optical photons emitted by the particles as it travels faster than the speed of light in a certain medium.

This is overall a simple setup to demonstrate and simulate the generation of the characteristic ring pattern of the generated photons.

## Geometry

For this simulation, we assume that some particle travels in a straight line along the z-axis through an aerogel radiator (10x10x5 cm), emitting photons uniformly along its path, where those photons project onto a flat SiC detector array located at a distance (appx. 30 cm) away (see richDetectorConstruction.cc in src file).

## Generator Action 

By default, the particle is set to be a pi- at 3 GeV (see PrimaryGeneratorAction.cc in src file). 

## Data Output

The program is set to only consider any generated G4OpticalPhoton particles and ignore other particles generated by the interaction (see SensitiveDetector.cc in src folder). The position and energy deposition of the G4OpticalPhoton is recorded (the pre-step point, where the particle is at the boundary crossing). The particle tracking is set to be killed after the interaction with the detector, since the information of interest here is the position of each hit. The energy deposition should be zero (currently it's getting the post-step energy, which is of no interest.
The ROOT file output (found in DataOutput folder) contains data on photon coordinates and energy deposition.

## Analysis

The ROOTanalysis.py file is meant for output analysis using uproot. This generates a 3D plot of the photon hits using the optical photon coordinates and plots energy deposition distribution. Since this project tracks G4OpticalPhotons, the energy deposition is zero (and is killed after hitting the detector). 

## Build Instructions

To build this project, install Geant4 and CMake. Use the CMakeLists.txt to build the project and run the executable file. The project can be built the same way as Geant4 example projects.
